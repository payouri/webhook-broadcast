# Admin API contract shape

Admin surface is unversioned URL paths under `/` (no `/v1`), identified by opaque UUIDs; Channel slug is ingest-only. Collections always return `{ items, nextCursor }` with opaque keyset cursors (`limit` default 50, max 100). Ingest tokens are hashed at rest, plaintext returned once on create, listed as `{ id, prefix, createdAt }`. Errors use one envelope `{ error: { code, message, details? } }`. Auth is a single operator API key via `Authorization: Bearer` (OpenAPI `http` bearer) or the same value in an HttpOnly session cookie for the dashboard. `POST /ingest/:slug` is **outside** the published admin OpenAPI (channel-token auth, arbitrary body). Breaking change = remove/rename/retype a published field or path; additive changes are compatible. The OpenAPI 3.1 sketch lives at `docs/contracts/admin.openapi.yaml` and will later be emitted from Zod and diffed in CI.
