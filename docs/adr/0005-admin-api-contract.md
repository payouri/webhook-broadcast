# Admin API contract shape

Admin surface is unversioned URL paths under `/` (no `/v1`), identified by opaque UUIDs; Channel slug is ingest-only. Collections always return `{ items, nextCursor }` with opaque keyset cursors (`limit` default 50, max 100). Ingest tokens are hashed at rest, plaintext returned once on create, listed as `{ id, prefix, createdAt }`. Errors use one envelope `{ error: { code, message, details? } }`. Auth accepts multiple concurrent operator credentials via `Authorization: Bearer` (OpenAPI `http` bearer): the bootstrap `OPERATOR_API_KEY` or any unrevoked `operator_token` minted/revoked through `POST /operator-tokens` / `DELETE /operator-tokens/{id}` (issue #41), each independently revocable and equally privileged — no scoping or roles. Only the bootstrap key can also be exchanged at `POST /auth/login` for the HttpOnly session cookie the dashboard uses; minted operator tokens are bearer-only and cannot log into the dashboard. `POST /ingest/:slug` is **outside** the published admin OpenAPI (channel-token auth, arbitrary body). Breaking change = remove/rename/retype a published field or path; additive changes are compatible. The OpenAPI 3.1 sketch lives at `docs/contracts/admin.openapi.yaml`, is emitted from Zod (`pnpm contract:emit`), and is diffed against that emission in CI (`pnpm contract:check`); see ADR 0012 for why the committed sketch stays one file while its Zod source is split by domain.

The contract is additionally served at runtime by the api at `/openapi.json`, `/openapi.yaml`, and a rendered page at `/docs` (issues #107–#109, the renderer's own bundle at `/docs/scalar.js` behind the same gate). All four require an operator credential — either credential shape the admin surface already accepts, bearer token or the dashboard's HttpOnly session cookie — since every path the document describes already does; the cookie is what makes `/docs` reachable by browser navigation at all. They are gated by `DOCS_ENABLED` (default on), answering `404` with `docs_disabled` when off, so a deployment can opt out of serving the contract without the Scalar bundle ever being read off disk.
