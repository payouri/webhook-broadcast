# Repository layout and toolchain

pnpm workspaces monorepo: `apps/api` (Koa HTTP + BullMQ worker as two entrypoints), `apps/web` (Vite React dashboard), `packages/contract` (Zod → OpenAPI → typed client, in-repo only), `packages/db` (Drizzle schema + migrations). TypeScript **6.x** strict with `moduleResolution: bundler`; workspace packages consumed as source; API/worker production bundles via tsdown. Node **24** LTS, pnpm **11.1.2** (see root `packageManager`), Vitest + Testcontainers (Postgres/Redis), Oxlint + Prettier, `tsx watch` for API/worker dev and Vite for the dashboard. Turborepo/Nx deferred until package count justifies them.
